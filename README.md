# Week 4 Assignment: Grades, Eligibility & Smart Decisions

This assignment practices Python functions, parameters, return values, and default parameters.

## Files

- `welcome.py` - Contains the `welcome()` function and uses it to greet three people.
- `toolbox.py` - Contains the `double()`, `is_pass()`, and `greet()` functions and tests them.

## Hardest Function

The `greet()` function was the hardest to write because it uses a default parameter for the greeting while also allowing a different greeting to be provided.
